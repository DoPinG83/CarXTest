Руководство пользователя:

Большинство настроек игры вынесено в скриптабл-объект CoreConfig:
	levels - фиксированная последовательность уровней
	cyclingLevel - номер уровня, начиная с которого идет рандомный выбор следующего, если фиксированная последовательность в levels пройдена
	levelRewards - награда за уровень
	bulletDict - конфиги пуль
	enemyDict - конфиги врагов
	gunDict - конфиги пушек

В префабах уровней в папке _Prefabs/Levels можно указать расположение башен и пушек на них, а также точки спауна противников и цели, к которым они движутся по навмешу.
На 2-м уровне для противников реализованы 2 дорожки, на 1-м и 3-м - по одной. Можно добавлять свои уровни и менять их наполнение

	Еnemies - последовательность спауна врагов
	EnemySpawnPeriod - частота спауна врагов
	EnemiesKillToPass - сколько требуется убить врагов для победы

Сбросить прогресс можно с помощью команды в верхнем меню Tools -> Clear Player Prefs.

В проекте имеются 2 сцены:
Bootstrap - загрузочная сцена, запускающая очередь тасок для инициализации менеджеров и спаун-пуллов для игровых обьектов и Gui-элементов
GameProd - основная игровая сцена

Запускать игру следует либо со сцены Bootstrap, либо с помощью команды в верхнем меню Dev -> Start Play Game, которая автоматически переключит редактор в нужную сцену. 

Основными классами, отвечающими за геймплей являются:
	Конфиги - в папке _Scripts/Game/_Configs
	Менеджеры - в папке _Scripts/Game/_Managers
	Инфошки - в папке _Scripts/Game/_Infos
	Системы - в папке _Scripts/Game/_Systems
	Вспомогательные математическме функции - в классе ShootingUtils.cs

В игре довольно много вспомогательного кода, не относящегося напрямую к требуемому функционалу, но я считаю, что нужно использовать свой опыт и имеющиеся наработки, позволяющие обеспечить относительно качественную, масштабируемую и надежную архитектуру в кратчайшие сроки, а не изобретать велосипеды для каждой требуемой подсистемы.

Требуемый в ТЗ функционал реализован полностью, однако система выстрелов с учетом гравитации требует математической доработки - работает не всегда стабильно ¯\_(ツ)_/¯
